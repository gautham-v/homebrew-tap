# homebrew-tap

```
brew install gautham-v/tap/msgs
```

Formulae:

- `msgs` — a terminal client for iMessage on macOS: https://github.com/gautham-v/msgs
- `catcher` — a minimal, local-first markdown notes TUI: https://github.com/gautham-v/catcher

Casks:

- `claudebar` — Claude usage limits in the macOS menu bar: https://github.com/gautham-v/claudebar

```
brew install --cask gautham-v/tap/claudebar
```
